fog

a functional language for lazy programmers

What's fog?

fog is a general-purpose, purely functional toy language with imperative-style syntax, made as a "fun" "side" project. It is planned to be

  • strongly and statically typed,
  • eagarly evaluated, with explicit laziness, and,
  • compiled to machine code.

Why name it fog?

  • fog looks like f ∘ g, where ∘ denotes function composition. This language is a functional language so it fits.
  • I had a brain fog making this language.
  • You will have a brain fog writing in this language, too.
